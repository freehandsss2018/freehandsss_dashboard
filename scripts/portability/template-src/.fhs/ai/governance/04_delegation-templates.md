# 04 — 委派模板

> Version: 0.1.0。以下是合約格式，按任務填寫；不得用模糊的「幫我看看」代替驗收。

## T1 搜尋與定位

```text
目標：找出 {問題} 的現行定義及呼叫位置。
範圍：只讀 {目錄}；大檔先搜尋，單窗口不超過 250 行。
驗收：列出定義、使用者及可能衝突，每項附路徑與行號。
回報：結論不超過 30 行；長清單存檔並只回報路徑。
```

## T2 實作

```text
目標：在 {範圍} 達成 {可觀察結果}。
約束：不得改動 {排除檔案}；保留 {不變量}。
驗收：執行 {測試或演練}，列出輸出及剩餘風險。
回報：改動摘要、檔案清單、測試結果與信心。
```

## T3 重構

```text
目標：調整 {結構}，保持 {行為} 等價。
先記錄舊版基線；按小步提交；每步核對差異。
驗收：新版與基線逐項一致，必要效能門檻通過。
回報：差異、證據、未覆蓋情況與回退方法。
```

## T4 研究

```text
目標：釐清 {決策問題}。
來源：以原始文件或官方資料為先，核對日期及適用版本。
驗收：比較選項、證據、限制與建議。
回報：短結論與可直接開啟的來源連結。
```

## T5 審查

```text
目標：對 {變更} 作獨立審查，找出會令驗收失效的反例。
範圍：只讀差異與必要上下文，不接受作者的成功聲明作證據。
驗收：每項發現附重現步驟或行號、嚴重度、修正建議。
回報：先列阻擋項；無發現則說明實際檢查了甚麼。
```

## T6 交接膠囊

記下目標、當前版本、已完成證據、未完成事項、下一個命令及不可破壞的不變量。交接者只需這份膠囊便能繼續，不應依賴私人聊天記憶。

## T7 並行彙整

為各路分配獨立範圍和檔案所有權；指定同一回報格式。彙整者核對矛盾、重複和未覆蓋區域，再做裁決。具體安全條件見 [07_compounding-loop.md](07_compounding-loop.md)。
