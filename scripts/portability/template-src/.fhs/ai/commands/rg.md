# /rg — 定位專案文字

**依賴**：`rg`（ripgrep）；無此工具時使用平台內建等效搜尋。
**不可攜平台**：無；只要有檔案搜尋能力即可。
**副作用**：唯讀。

語法：`/rg <pattern> [--filter <glob>] [--path <dir>] [-i]`。

1. 解析關鍵字或正則、檔案 glob、搜尋根路徑及是否忽略大小寫。缺 pattern 時請用戶提供，或從當前問題提取明確搜尋目標。
2. 從專案根目錄執行 `rg -n`；預設排除 `.git/`、`node_modules/`、生成 artifacts。搜尋太廣時先列檔名或縮小路徑，避免巨量輸出。
3. 顯示 `路徑:行號:匹配內容`，統計匹配數與檔案數。零結果如實回報，不推斷代碼不存在；檢查大小寫、同義詞及忽略規則後再給建議。
4. 需要上下文時只讀匹配附近的小窗口；巨檔不得全檔讀取。任何寫入或取代須另行明確授權。
