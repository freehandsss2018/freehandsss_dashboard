# /8d — 八維度方案迭代

**依賴**：`.fhs/ai/commands/rp.md` 中的 `architecture_scan` 維度定義；可選當前對話已有方案。
**不可攜平台**：無；純對話分析，不需外部服務。
**副作用**：唯讀，不產生 artifacts。

1. 有參數時分析參數指定的方案；沒有參數時分析對話中最近的明確方案。找不到對象就請用戶提供，停止。
2. 寫出方案草案與可執行的步驟；已存在完整草案時直接引用並指出關鍵環節。
3. 找三個具體弱點，每個說明會失效的條件及後果。若實際不足三個，說明已找到的數量與查證依據，不湊數。
4. 提出修正後版本，逐項回應弱點。依 `/rp` 的八個維度檢查修正版，標相關或不適用並說明影響。
5. 若方案涉及 agent、hook、skill 或跨平台文件，另外檢查 Claude Code、Antigravity 與 VS Code 的路徑和載入差異；純領域方案可標不適用。
6. 單則回覆交付草案、弱點、修正版、維度檢查與結論。是否實作仍依 `{{OWNER}}` 授權及 `.fhs/ai/AGENTS.md` 規則決定。
