# /read — 載入專案狀態

**依賴**：`.fhs/notes/SOP_NOW.md`；可選 `.fhs/memory/handoff.md`、`.fhs/memory/MEMORY.md`、`.fhs/ai/AGENTS.md`。
**不可攜平台**：無；任何可讀取專案檔案的平台均可執行。
**副作用**：唯讀。

一般 session 優先使用啟動快照；遇跨長時間交接、複雜決策或需要核實待辦細節時執行本指令。

1. 從專案根目錄確認主檔 `.fhs/notes/SOP_NOW.md` 存在。不存在就報告路徑並停止；不要猜測其他位置。
2. 依序讀主檔、handoff 的便攜摘要塊、MEMORY 索引及 AGENTS 憲法摘要。巨檔先搜尋標題再讀相關窗口，不全檔傾倒。
3. 如主檔指向其他必讀文件，逐一驗證路徑後按需讀取。個別可選檔不存在時記錄並繼續。
4. 回報已讀文件、當前專案 `{{PROJECT_NAME}}` 的狀態、未解待辦、衝突與需要 `{{OWNER}}` 裁決的事項。引用來源路徑；無證據的狀態標示為未知。
