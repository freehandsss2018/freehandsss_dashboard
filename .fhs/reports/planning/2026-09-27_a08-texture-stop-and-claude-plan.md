# Amen 左腳紋理：A08 R3 停止試作與 Claude 續作方案

日期：2026-09-27。狀態：**Fat Mo 親自判斷效果未如理想、未達預期；A08 R3 停止在現有進度，交 Claude Code 跟進。** 本文件是最新交接入口。A01–A08 均非 Fat Mo 已簽收的紋理樣板；A08 R3 不得當成打印檔或訓練成功案例。

## 任務與既定要求

對同一隻 Amen 左腳，先按實拍照片初步定位腳趾紋路，再參照師傅中間版的雕刻方式做出**很深、柔和、自然**的摺紋。深谷須嵌在連續的肉墊形態中，不能只留下孤立切口；甲緣框感目前不是首要驗收門檻。這是單一客戶個案試驗，正式 Pipeline v0 的紋理由師傅負責，AI 的既定縮放、刻字、加環與 QC 分工未改。

## 本輪做到了甚麼，為何仍失敗

1. 主定位照片為 `IMG_9427.JPG`（白色實體腳模的腳背）；`IMG_9432.JPG` 作斜角目視覆核。八張照片均已檢視。9427 EXIF Orientation=6，轉正後 3024×4032。按每趾輪廓建立人工條帶對應，把五段照片描線投到 RAW：大趾 B1 甲後主紋、B2/B3 趾根過渡紋、第二趾 S1 主紋、第三趾 T1 可見淺段。照片沒有給出可靠的深度資料；對位並非標定相機或有量化誤差的攝影測量。
2. 初版 A08 的法線位移留下鋸齒、針坑；該方法已拒用。R2/R3 改用一致共邊細分、局部抗離群皮面整理及相機平面高度場。R3 有比 A07 更長的紋路與斜視下可辨的深谷，首版碎面問題在新槽核心不再顯著。
3. **Fat Mo 的實際裁決優先於代理的機械 QC 或視覺自評：效果未達預期，停止。** 本輪圖可見 B2/B3 中間的皮面像被兩道槽夾出的獨立圓角墊；B1/S1 槽尾有折向趾根的短溝，收筆仍有框邊／刻槽感。深度變明顯沒有解決自然過渡。師傅版的長弧、局部深谷、肉墊連續性仍未達到。
4. 獨立唯讀 blender-3d-modeler 的閱圖意見與上述缺陷一致，但**不代表 Fat Mo 簽收**。關於缺陷成因，平面高度場、人工對位及局部光順是待檢假設，未被單獨證實為全部根因；不可只再調深度參數宣稱修好。

## 給 Claude Code 的下一輪方案

1. **先建立可比對的失敗標記。** 在同相機、同照明的照片／RAW／A08 R3／師傅圖上逐一標示 B1、B2、B3、S1 的兩端、谷底和兩側肉墊。把「照片能證實位置」與「師傅版提供的雕刻語言」分開記；重核大趾與第二趾縫端的 B2/B3 位置。若嘗試相機標定，要列清楚可見地標及留出的驗證地標，報對位誤差；做不到就繼續標為人工初對位。
2. **診斷幾何問題後換造型方法。** 在大趾 B1 和 B2/B3 各取數段實際網格截面，看谷底寬度、兩側坡度、端點深度與隆起是否連續；師傅參照只有近似姿態，不可直接做逐點差分。針對 R3 的圓墊與折角，優先重塑局部連續皮面與不對稱摺疊，可試 Blender 局部手工雕刻／重建或更可靠的每趾表面表示；平面高度場與全線加深已無充分成效證據。
3. **先交一個大趾局部版本。** 先只處理 B1 主紋及相鄰肉墊，保留它的強深谷視覺重點，同時讓谷底、隆起及兩端分別漸退，不留下封口或獨立墊塊。用 RAW、A08 R3、師傅版作對照；不要一次把五條紋重做後才讓 Fat Mo 判斷。大趾過關後再處理 B2/B3，其後才第二、第三趾。
4. **交可目測的證據。** 同角度同照明一張整體圖、一張放大圖、一張斜側圖；另附局部截面或網格診斷。由 Fat Mo 分別判「照片位置是否對」「深度是否夠」「肉墊和收筆是否自然」。任一未通過就留在試作，不升格為共用參數、跨代理記憶中的成功範例或生產流程。
5. **視覺獲 Fat Mo 接受後才做製造檢查。** 再驗自交、壁厚、實際尺寸、封閉性、輸出與師傅／廠家要求；之後用未見過的第二個腳樣本檢查是否可泛化。全程只改副本，保留原掃描、師傅檔和照片。

目前最具體的下一個動作是 Claude 先做第 1–2 步的標記與幾何診斷，再交**單一大趾局部造型版**供 Fat Mo 目測。這份方案不是批准 Claude 現有 A08 模型進入打印。
